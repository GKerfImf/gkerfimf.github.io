Counterexample to the Critical Instant Theorem

Formalizes Counterexample 10 from: "Critical Instant for Probabilistic Timing Guarantees: Refuted and Revisited" Chen, Günzel, von der Brüggen, Chen (RTSS 2022).
Setup (all times scaled ×10 to obtain integers): τ₁: period T₁ = 40, P(C₁ = 10) = 9/10, P(C₁ = 25) = 1/10 (higher priority) τ₂: period T₂ = 44, deadline D₂ = 44, C₂ = 30 (lower priority)
Result: P(R₂,₁ > 44) = 1/10 (first job, synchronous release) P(R₂,₆ > 44) = 19/100 (sixth job, suffers carry-in interference) Since 1/10 < 19/100, the critical instant theorem is unsound.

Section CounterexampleSetup.

Constants


  Let T₁ : nat := 40.
  Let T₂ : nat := 44.
  Let D₂ : nat := 44.
  Let C₂ : nat := 30.
  Let C₁_short : nat := 10.
  Let C₁_long : nat := 25.

Job Type

13 jobs indexed by 'I_13: 0..6 are τ₁,₁ .. τ₁,₇ (higher priority) 7..12 are τ₂,₁ .. τ₂,₆ (lower priority)

  Let Job := [finType of 'I_13].

  Definition is_τ₁_job (j : Job) : bool := (j < 7)%nat.

  Definition arrival_of (j : Job) : instant :=
    if is_τ₁_job j then (nat_of_ord j × T₁)%nat
    else ((nat_of_ord j - 7) × T₂)%nat.

Sample Space and Measure

The only randomness is the execution time of the 7 τ₁ jobs. Ω = {ffun 'I_7 → bool}: for each τ₁ job index i : 'I_7, ω i = true means short execution (C₁ = 10), ω i = false means long execution (C₁ = 25).
Each τ₁ job is an independent Bernoulli(9/10) trial.

  Let Ω := [finType of {ffun 'I_7 → bool}].

  Definition count_true (ω : Ω) : nat :=
    count (fun i : 'I_7 ⇒ ω i) (enum 'I_7).

  Definition ce_pmf : Ω → R :=
    fun ω ⇒ (9/10) ^ count_true ω × (1/10) ^ (7 - count_true ω).

  Lemma ce_pmf_pos : ∀ a : Ω, ce_pmf a ≥ 0.
  Admitted.

  Lemma ce_pmf_sum1 : is_series (countable_sum ce_pmf) 1.
  Admitted.

  Definition μ : measure Ω :=
    {| pmf := ce_pmf; pmf_pos := ce_pmf_pos; pmf_sum1 := ce_pmf_sum1 |}.

Job Parameters

Job Costs

  Definition job_cost_val (j : Job) (ω : Ω) : option work :=
    match (j < 7)%nat as b return (j < 7)%nat = b → option work with
    | true ⇒ fun H ⇒ Some (if ω (Ordinal (n:=7) H) then C₁_short else C₁_long)
    | false ⇒ fun _ ⇒ Some C₂
    end (erefl _).

  Instance job_cost_rv : JobCostRV Job Ω μ :=
    fun j ⇒ mkRvar μ (fun ω ⇒ job_cost_val j ω).

Job Arrivals

  Instance job_arrival_rv : JobArrivalRV Job Ω μ :=
    fun j ⇒ mkRvar μ (fun _ ⇒ Some (arrival_of j)).

Scheduler

We assume a scheduling algorithm ζ and derive the probabilistic schedule from it.

  Variable ζ : @scheduler𝗔𝗖 Job.

  Let sched := @compute_pr_schedule Ω μ Job job_arrival_rv job_cost_rv ζ.
  Let horizon : option instant := None.

Named Jobs and Indices


  Let j_τ₂₁ : Job := Ordinal (n:=13) (erefl : (7 < 13)%nat).
  Let j_τ₂₆ : Job := Ordinal (n:=13) (erefl : (12 < 13)%nat).

  Let RT_exceeds_τ₂₁ : pred Ω :=
    response_time_exceeds sched horizon j_τ₂₁ D₂.

  Let RT_exceeds_τ₂₆ : pred Ω :=
    response_time_exceeds sched horizon j_τ₂₆ D₂.

  Let idx0 : 'I_7 := ord0.
  Let idx5 : 'I_7 := inord 5.
  Let idx6 : 'I_7 := inord 6.

Scheduling Lemmas


  Lemma sched_miss_τ₂₁ :
    ∀ ω : Ω, RT_exceeds_τ₂₁ ω = ~~ ω idx0.
  Admitted.

  Lemma sched_miss_τ₂₆ :
    ∀ ω : Ω, RT_exceeds_τ₂₆ ω = ~~ (ω idx5 && ω idx6).
  Admitted.

Probability Lemmas


  Lemma pr_single_long :
    ∀ (i : 'I_7),
      ℙ<μ>{[ fun ω : Ω ⇒ ~~ ω i ]} = 1/10.
  Admitted.

  Lemma pr_pair_short :
    ∀ (i j : 'I_7), i != j →
      ℙ<μ>{[ fun ω : Ω ⇒ ω i && ω j ]} = 81/100.
  Admitted.

Main Results


  Lemma miss_prob_τ₂₁ :
    ℙ<μ>{[ RT_exceeds_τ₂₁ ]} = 1/10.
  Admitted.

  Lemma miss_prob_τ₂₆ :
    ℙ<μ>{[ RT_exceeds_τ₂₆ ]} = 19/100.
  Admitted.

  Theorem counterexample_refutes_critical_instant :
    ℙ<μ>{[ RT_exceeds_τ₂₁ ]} < ℙ<μ>{[ RT_exceeds_τ₂₆ ]}.
  Admitted.

End CounterexampleSetup.
